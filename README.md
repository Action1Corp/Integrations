# Integrations
Integration scripts based on Action1 APIs and third-party APIs

## Entra → Action1 Connector

A lightweight connector that synchronizes device data from Microsoft Entra ID into Action1, enabling dynamic grouping and automation in Action1 based on Entra ID device group membership.
[Documentation](entra-action1-connector/README.md)

## Action1 -- Intune Agent Application Manager

The **Action1 -- Intune Agent Application Manager** script automates the deployment and lifecycle management of the Action1 Agent within Microsoft Intune, ensuring endpoints always have the latest agent version installed.
[Documentation](Intune-App-Manager/README.md)
